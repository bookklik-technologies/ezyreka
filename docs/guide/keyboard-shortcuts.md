# Keyboard shortcuts

Ezyreka implements a full Canva-style shortcut set. Multi-instance pages keep shortcuts scoped to the focused editor.

## General

| Shortcut | Action |
| --- | --- |
| `Ctrl/⌘ + Z` / `Ctrl/⌘ + Shift + Z` | Undo / redo |
| `Ctrl/⌘ + C` / `X` / `V` / `D` | Copy / cut / paste / duplicate |
| `Ctrl/⌘ + A` | Select all |
| `Delete` / `Backspace` | Delete selection |
| `Escape` | Deselect / finish text editing |
| `Ctrl/⌘ + S` | Save design file |
| Double-click | Edit text in place |

## Moving & selecting

| Shortcut | Action |
| --- | --- |
| `Arrows` | Nudge 1px |
| `Shift + Arrows` | Nudge 10px |
| `Shift` + click | Add to selection |
| Drag on empty canvas | Rubber-band selection |

## Zooming & panning

| Shortcut | Action |
| --- | --- |
| `Ctrl/⌘ + +/-` / `0` | Zoom in / out / fit |
| `Space` + drag | Pan canvas |
| Middle-mouse drag | Pan canvas |
| `Ctrl` + wheel | Zoom to cursor |

## Sidebar navigation

| Shortcut | Action |
| --- | --- |
| Up/Down arrows | Navigate focused tool tabs |
| Up/Down arrows (layers grip focused) | Reorder layers |
